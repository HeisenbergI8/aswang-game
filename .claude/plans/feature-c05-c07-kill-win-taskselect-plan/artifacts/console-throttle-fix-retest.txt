THIRD FIX ROUND — the respawn-throttle stranding bug, fixed and re-tested against its own repro.
Roblox Studio, 2026-08-11. Config debug: Intermission widened to 30s so the whole repro runs in the
LOBBY (the branch the bug lived in); Duration/EndScreen 45/6; Solo/Verbose/ForceAswang true. Reverted.

THE BUG (confirmed live by an independent playtester before this fix, and by two code reads):
  watchForDeath's rate limit returned ABOVE `player.Character = nil`, so a second death inside the
  3-second window left a DEAD character attached. applyBodyRule's load branch is gated on
  `Character == nil`, so nothing ever repaired it — permanent for the server session, not for 3s.
  Worse: STARTING still dealt the corpse in as ALIVE, leaving them eligible for the Aswang draw, and
  if drawn neither round-abort path could fire because MarkKilled never runs for them.

THE FIX: detach and destroy ALWAYS; throttle only the LoadCharacterAsync, and DEFER it via task.delay
rather than dropping it. The body always goes, which leaves `Character == nil` — a state the body rule
can and will repair — and the cooldown still bounds the expensive half, which is all it was for.
