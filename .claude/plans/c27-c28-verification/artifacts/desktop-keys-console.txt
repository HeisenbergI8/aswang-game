METHOD, and why it is stronger than watching for a completed task:

  Four transient listeners were attached on the SERVER to RequestTaskProgress, RequestTimingStop,
  RequestThrowSalt and RequestTrialThrow — additive, recording only, discarded on Stop, and removed
  afterwards (4 listeners disconnected, _G cleaned). The real handlers still ran. What this records
  is exactly the link C27 refactored: key -> ContextActionService handler -> performAct /
  performTimingStop / performThrow -> FireServer.

  This needs no walking to a task point, because none of the three remotes is gated client-side:
  the hold heartbeat fires while `holding` regardless of position, the timing stop fires
  unconditionally by design (InputController documents the token cost of that choice), and the throw
  sends a camera direction with no local pouch check. The SERVER refuses what it should; the point
  under test is whether the key still reaches the wire at all.
