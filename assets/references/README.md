# references/

Real photos, downloaded. Claude reads these directly — they are input to its eyes, and they never go
into the game.

**Never put a generated image here.** An AI render of a bahay kubo is a guess, and building from it
means copying the guess. A real photo is free and correct.

**A screenshot of another Roblox build belongs here too, and is the single most useful thing you can
add.** Everything visible in one is reproducible by definition, so it removes the "is this even
possible" question before any work starts.

Subfolder per subject: `bahay-kubo/`, `fence/`, `chapel/`.
