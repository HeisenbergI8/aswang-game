# decals/

Non-tileable artwork: sari-sari signage, a santo painting, a poster, a warning notice.

This is the main image-generation lane — the things no tool in this toolchain can make.

Every file here was generated flat-on and orthographic, with **no baked lighting or shadow** and a
transparent background where it is not a full rectangle. The game supplies the angle and the light; a
shadow painted into the image fights the scene and reads as dirt.
